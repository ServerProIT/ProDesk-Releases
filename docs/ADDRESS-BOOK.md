# Адресная книга ProDesk

На Windows откройте вкладку **Адресная книга** (значок книги). Вход в аккаунт
RustDesk и платный API-сервер не требуются. Книга хранится локально, отдельно
для каждого пользователя Windows.

- **Новая папка** создаёт папку внутри выбранной; в корне — папку верхнего уровня.
- Меню `⋮` у папки позволяет создать подпапку, изменить название, выбрать один
  из десяти цветов, переместить папку или удалить её вместе с содержимым.
- **Новое подключение** сохраняет название, ID/IP компьютера и заметку в
  выбранную папку. Расположение можно поменять при редактировании записи.
- Нажатие на подключение открывает удалённый рабочий стол. В меню записи
  доступны передача файлов, редактирование, перенос и удаление.
- Поиск просматривает всю книгу по названию, ID/IP и заметке.
- Стрелка рядом с папкой сворачивает и разворачивает её подпапки.

## Импорт и экспорт

**Экспорт JSON** сохраняет всю книгу в `ProDesk-address-book.json`: дерево,
цвета, названия, ID/IP и заметки. Пароли подключений в этот формат не входят.
Подключение использует обычный механизм запроса/сохранения пароля приложения.

**Импорт JSON** проверяет файл и показывает количество папок и подключений.
После подтверждения записи добавляются к текущим. Существующие записи
сохраняются; повторный импорт создаёт отдельные копии. Внутренние идентификаторы
переназначаются с сохранением родительских связей. Повреждённый файл, циклы,
несуществующие папки и неподдерживаемая версия формата отклоняются до записи.

Поддерживается формат `ProDeskAddressBook`, версия `1`, файл до 10 МБ и дерево
до 64 уровней. Импорт сторонних форматов RustDesk в эту версию не входит.

Данные находятся в подкаталоге `ProDesk/address-book.json` каталога поддержки
приложения пользователя; базовый путь определяется системным
`getApplicationSupportDirectory` внутри `%APPDATA%`.
При записи предыдущая копия сохраняется рядом как `address-book.json.bak`.
Обновление программы в Program Files не удаляет эту папку.

Локальная книга ProDesk не синхронизируется через сервер. Для переноса между
компьютерами используйте экспорт и импорт.
